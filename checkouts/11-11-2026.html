wat is css cascade en css specificty? (eigen woorden, met een tekening)

cascade

cascade is, voor zover ik het begrijp, de manier waarop css beslist welke regels te gebruiken als er meerdere regels over het zelfde stukje html gaan. bijvoorbeeld als er *{margin: 0} staat, en ook h2{margin: 0.5rem} staat. of als je zegt dat al je p's rood moeten zijn, maar p's met een specifieke class wit moeten zijn, dat css weet waar precies naar geluisterd moet worden. de cascade wil dus zeggen hoe css besluit welke regels het belangrijkst zijn en dat die toegepast worden in plaats van minder belangrijke regels

specificity

specificity is onderdeel van hoe de cascade besluit welke regels het belangrijkst zijn. Specificity wil zeggen: op hoe minder elementen dit van toepassing kan zijn, hoe belangrijker het is. regels op bijvoorbeeld alle P elementen zijn het minst belangrijk, daarna regels die in een class voorkomen, dan regels die in een ID voorkomen en tot slot regels die in inline css voorkomen
